# 20 Kurzvideo-Skripte (TikTok / Reels / Shorts)

Regeln: keine Angstmache, keine unbelegten Zahlen, keine erfundenen Erfahrungsberichte, keine Countdown-Rabatte.
Länge jeweils 20–40 Sekunden. CTA immer ruhig. Quellen für Fakten stehen in Klammern – vor Veröffentlichung prüfen.
